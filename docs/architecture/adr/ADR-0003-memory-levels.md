# ADR-0003: 保留并扩展分层记忆系统

## 状态
已接受

## 背景
GenericAgent 拥有独特的五层记忆系统（L0-L4），这是其自我进化能力的核心：
- L0：元规则（永久）
- L1：记忆索引（永久）
- L2：全局事实（永久）
- L3：任务 Skills（永久）
- L4：会话归档（临时）

这种分层设计使得 Agent 能够高效管理不同类型的知识。

## 决策
保留并扩展 GenericAgent 的分层记忆系统，作为新架构的记忆端口实现。

## 理由
1. **成熟设计**：五层结构经过实践验证
2. **自我进化核心**：Skills 结晶机制是 GenericAgent 的独特优势
3. **Token 高效**：分层设计减少上下文窗口浪费
4. **可扩展**：可以接入向量存储等高级特性

## 结果
- `LayeredMemory` 类实现 `MemoryPort` 接口
- 每个记忆条目包含级别、置信度、访问计数等元数据
- 支持经验结晶（crystallize）机制

## 代价
- 记忆迁移需要保持兼容性
- 分层边界需要清晰定义
