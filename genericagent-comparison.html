技术架构

🐍 genericagent-launcher
  • Python + CustomTkinter (GUI)
  • PyInstaller (打包)
  • Inno Setup (Windows安装器)
  • Ed25519 + SHA256 (签名验证)
  • Qt/CustomTkinter 前端
  • Bridge.py 桥接层
  • 外部更新器 + 自动回滚
🦈 ga-manager
  • TypeScript + Electron
  • React 前端
  • Go backend (bridge)
  • Python backend (GA通信)
  • electron-builder (打包)
  • electron-updater (自动更新)
  • 多窗口架构
🍽️ galley
  • Python + Go (混合)
  • 内置 GenericAgent runtime
  • bundled CPython 3.11
  • GUI + CLI 双原生
  • galley CLI 公开契约
  • Browser Control 内置
  • Project 多会话编排
⚙️ GenericAgent-Admin Go
  • Go 后端 (进程/文件/配置)
  • React/Vite 前端
  • 单文件分发 (ga-admin)
  • 复用 GA 官方 chat_worker
  • Goal/Hive 官方逻辑
  • 外置 BBS 服务
  • WebDriver 支持

综合评价

🥇 genericagent-launcher
Stars 最高 (130)，功能最全面。独有渠道管理（微信/Telegram/QQ/飞书等）、远程设备/VPS接入、定时任务面板。最适合需要完整生态的企业用户或重度用户。Windows优先，macOS支持稍弱。
🥈 galley
开源精神最佳 (395 commits, MIT)。内置Runtime + CLI入口，适合开发者和技术用户。多Session并行和Goal工作流是亮点。跨平台最完整。
🥉 ga-manager
最活跃的开发 (200+ releases)。Desktop Pet 和 Rewind 时光机等独特功能。多实例管理成熟。Electron + React 技术栈，跨平台体验一致。适合个人多任务用户。
🏅 GenericAgent-Admin Go
最新 (今日更新)，架构最独特 (Go后端 + React前端)。单文件分发最方便。适合需要轻量管理和系统集成的用户。目前Stars最少但发展迅速。
